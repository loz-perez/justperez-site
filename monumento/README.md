# Monumento Innecesario

Generador de monumentos conmemorativos absurdos con su historia oficial.
Homenaje a lo que nadie pidió recordar.

Escribí a quién o qué querés conmemorar, o dejá el azar decidir. La placa,
el material, la altura y la fecha se generan solos, y una imagen del
monumento se genera por IA (Seedream 5.0 Lite vía OpenRouter).

- 100% en el navegador — un solo archivo, sin backend.
- La imagen se cachea en localStorage para no regenerar el mismo monumento dos veces.
- Requiere una key de OpenRouter embebida (gasta ~$0.035 por imagen nueva).

Live: https://justperez.uk/monumento/
