# Generador de Crisis Post-Cumpleaños

Un generador de crisis existencial humorístico. Ingresá tu edad y recibí una frase sombría, sarcástica y entretenida sobre el paso del tiempo.

Parte del ecosistema [casa-perez](https://justperez.uk).

## Cómo funciona

1. Ingresá tu edad (1–110)
2. Apretá "Generar Crisis"
3. Recibí una frase personalizada para tu rango etario
4. Si te agarra la desesperación, tocá "No me hagas pensar en eso" → "Ya es tarde."

Las frases están organizadas por rangos de edad y se eligen aleatoriamente. Sin repetición consecutiva.
