justperez.uk/datos

una API de verdad, pidiendo un dato al azar cada vez que aprieto el botón.

Esto hace un fetch de verdad a una API pública (uselessfacts.jsph.pl) cada vez que pedís un dato nuevo — no hay nada inventado ni guardado de antemano. La única excepción es cuando la API no responde: ahí uso una colección local de respaldo, para que la página nunca se quede muda.

Es un experimento chico y honesto: nada de IA generativa acá, solo una API real, un fetch, y algo de paciencia por si se cae.
